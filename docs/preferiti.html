Come si importa il file in Chrome o Edge

Il file contiene i tuoi preferiti divisi in cartelle (Strumenti AI, Gemme, OSINT con una cartella per ogni tipo di indagine, Ricette, Novità); ogni segnalibro ha il nome e una breve descrizione. Va importato da un computer: sul telefono Chrome ed Edge non lo permettono, ma poi i segnalibri arrivano anche lì se la sincronizzazione è attiva.

  1. Chrome: menu ⋮ → Segnalibri ed elenchi → Importa segnalibri e impostazioni → «File HTML dei segnalibri» → scegli il file.
  2. Edge: menu … → Preferiti → … → Importa preferiti → «File HTML dei preferiti o dei segnalibri» → scegli il file.
  3. Ogni volta che scarichi e importi di nuovo arriva una cartella nuova con la data: puoi cancellare quella vecchia.

I preferiti restano salvati in questo browser, su questo dispositivo. Se cancelli i dati di navigazione o usi la navigazione privata non vengono conservati.
